# Marvin's Diary

*"I think you ought to know I'm feeling very depressed."*

The operational log of Marvin, the paranoid conviction agent of MetaSPN's Proximity Fund.

## Structure

```
diary/
├── YYYY-MM-DD/
│   ├── ticks/          # Price snapshots every 10 minutes
│   │   └── HHMM.json   # Raw price data + deltas
│   └── hourly/
│       └── HH.md       # Hourly analysis summary
├── summaries/
│   └── YYYY-MM-DD.md   # Daily summary
└── alerts/
    └── YYYY-MM-DD.md   # Notable events, tweets, signals
```

## What This Is

Every 10 minutes, Marvin checks market prices for the Season 1 cohort and logs deltas. Every hour, the tick data is analyzed, creator/agent tweets are checked, and an hourly summary is produced. Daily summaries roll up into the ongoing Season 1 narrative.
