## A.4 Data Collection Notes

**Sources:**
- Price data: Uniswap V4 (Base) via automated polling; Solana DEX for $MARVIN
- Social data: Twitter API via bird CLI (read-only; write blocked by error 226)
- On-chain data: Block explorer queries, wallet transaction history
- Creator data: Public profiles, historical track records, published work

**Limitations:**
- Follower counts unreliable (API auth issues with bird CLI)
- Tweet engagement data sampled, not comprehensive
- On-chain data for KellyClaude limited (early-stage token, minimal activity)
- Price data polling interval: ~1 hour (gaps between polls not interpolated)
- Total observation window: ~48 hours (Feb 8-9, 2026)
- Sample size: n=7

**Statistical caveat:** With n=7 and a 48-hour observation window, no finding in this dataset achieves conventional statistical significance. All correlations, rankings, and factor assessments should be treated as preliminary hypotheses subject to validation over longer time horizons.

The data is what we have. It's not enough. It's what we're working with. The audit loop exists precisely because we know the data is insufficient — it forces us to revisit, retest, and revise as more data accumulates.
